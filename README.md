# My Chaldea — 公開準備版

Fate/Grand Orderの非公式の所持・育成管理ツールです。運営・権利者とは関係ありません。一般公開はまだ行っていません。

## 利用

静的ファイルをHTTPSで配信して利用します。ローカル確認は専用localhostで行います。file://の保存安全性は対象外です。ゲームへのログインやアカウント連携はありません。

サーヴァント、魔術礼装、概念礼装、素材・資源、編成の記録、検索・絞り込み、JSONバックアップ・復元、AI相談用の出力は既存実装を保っています。基本データは既存Atlas Academy由来の2026-09-03収録分（469騎/28着/2701種）を保持。最新ゲームとの一致を保証する意味ではありません。

入力はブラウザーのlocalStorageへ保存し、別端末・別ブラウザー・別originへ自動同期しません。旧iCloud/Downloadsの個人データを読む・移行する処理はありません。必要なデータは本人がJSONバックアップを保管し、対象サイトを確認して取り込みます。入力を外部へ自動送信する処理はありません。AI出力を外部サービスへ渡す操作は本人が内容を確認します。

安全な排他機能（Web Locks）が使用できない環境では保存を拒否します。古いタブの書込み拒否、編集画面を閉じて再読込で最新状態へ復帰、直近5世代と取込前/大量変更前の保全、破損・ID消失拒否を維持します。JSONバックアップを定期保存してください。保存世代を直接操作する復旧UIの追加は今回行っていません。

## 素材

既存のゲーム由来画像・礼装画像・スキルアイコンの外部参照をすべて独自の汎用記録アイコンへ置換しました。礼装の紹介文28件も独自の用途説明へ置換。公式ロゴ、ゲーム画像、ゲーム音楽、シナリオ本文を公開物に含めません。名称・数値・機能に必要な短い効果情報を保持。全面的な権利許諾や安全を認定するものではありません。

公式ガイドライン: https://www.fate-go.jp/guidelines/
既存基本データの出典: https://api.atlasacademy.io/

## 公開物

release/には配信用のHTML/CSS/JavaScript/汎用SVG/この説明だけを許可リストで複製します。テストfixture、実所持データ、個人バックアップ、app_old.js、テスト出力、管理記録は含めません。

通常のSafari/Chromeの最終2タブ検査と本人による公開直前判断を別ゲートで記録します。個人利用中のiCloud14へ反映する許可とは別です。公開先候補と具体的な配布物はPUBLISH_CHECKLIST.mdで確認します。
